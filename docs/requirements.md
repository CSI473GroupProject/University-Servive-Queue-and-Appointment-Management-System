# Functional Requirements

FR-01: The system shall allow a student to select a registration service.

FR-02: The system shall allow a student to join a virtual queue for a selected registration service.

FR-03: The system shall assign a unique queue number to a student who successfully joins a virtual queue.

FR-04: The system shall allow a student to view their current queue position and status.

FR-05: The system shall allow a student to view available appointment slots for a selected registration service.

FR-06: The system shall allow a student to book an available appointment slot.

FR-07: The system shall prevent a student from booking an unavailable or already-booked appointment slot.

FR-08: The system shall allow a student to cancel an appointment according to the applicable cancellation rules.

FR-09: The system shall allow registration staff to view active queues and scheduled appointments.

FR-10: The system shall allow registration staff to call the next eligible student.
